# 2주차 응용 계층 프로토콜

서버와 클라이언트는 UTF-8 한 줄을 한 메시지로 사용합니다.
명령어는 대문자이며, 필드는 공백으로 구분합니다.
닉네임은 문자·숫자·밑줄 1~12자이고 공백을 허용하지 않습니다.
채팅은 앞뒤 공백을 제거하며 내부 공백은 유지합니다. 최대 길이는 Java String.length 기준 200입니다.

|---|---|---|---|---|---|---|---|
| 참가 요청 | /JOIN | /JOIN 닉네임 | /JOIN 준석 | 준석은 사용할 닉네임 | 클라이언트 → 서버 | TCP 연결 직후 10초 이내 | 유효성·중복·정원 검사 후 ID 배정 |

## 카드와 공개 상태

- 카드 무늬: S 스페이드 / H 하트 / D 다이아 / C 클로버.
- 숫자: 2~10, J=11, Q=12, K=13, A=14.
- 상태: WAITING은 대기, DEALT는 개인 카드 배분 완료.
- /TABLE에는 개인 카드 코드를 넣지 않습니다.
- /HAND는 전체 전달 함수를 사용하지 않고 해당 참가자의 소켓에만 전송합니다.
- 참가자가 바뀌면 WAITING과 빈 /HAND를 전송합니다. 방장은 현재 참가자 중 가장 먼저 접속한 사람입니다.
- 종료 메시지는 따로 보내지 않습니다. 소켓의 EOF를 받은 서버가 참가자를 제거합니다.

## 2주차 범위

/START는 개인 카드 배분까지 수행합니다. 다시 누르면 새 덱으로 재배분합니다.
공용 카드 공개, 베팅, 폴드, 승패 판정 메시지는 아직 구현하지 않았습니다.
