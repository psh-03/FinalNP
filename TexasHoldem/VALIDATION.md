# 검증 기록

검증일: 2026-10-28. 환경: Linux / OpenJDK 17.0.20.

| 검증 | 결과 |
|---|---|
| Java 17 전체 소스 컴파일 | 통과, `-Xlint:all` 경고 없음 |
| 실행 JAR 생성 | 서버/클라이언트 별도 생성 |
| Java 핵심 동작 테스트 | 85,829개 assertion 통과 |
| 무작위 게임 | 고정 seed로 350핸드, 2~6인·다양한 잔액·베팅 조합 |
| 족보 | 9개 분류, A2345, 키커, 두 트리플, 보드만으로 동점, 중복 카드 거절 |
| 팟 | 메인팟/사이드팟, 여러 단계의 올인, 미콜 반환, 폴드 제외, 홀수 칩 배분 |
| 차례 | 헤즈업 프리플롭/포스트플롭 순서, BB 옵션, 딜러 회전 |
| 레이즈 | 최소 증액, 짧은 올인의 재레이즈 제한, 누적 짧은 올인의 재오픈 |
| 서버 검증 | 비방장 시작, 이전 차례 토큰, 비정상 행동 거절 |
| 상태/개인 패 | 행동마다 칩 보존, 음수 잔액 없음, 중복 카드 없음, 상대 패 전송 없음 |
| 연결 관리 | 중도 입장, 차례 중/차례 밖 연결 종료, 자동 체크·폴드, 방장 변경 |
| 실제 TCP 통합 테스트 | 생성된 서버 JAR을 실행해 2인·6인 클라이언트 연결 검증 |
| 실제 통신 내용 | 분할/병합 메시지, 한글 채팅, 숨긴 개인 패, 중복 행동, 잘못된 금액, 쇼다운 |
| 실제 시간 제한 | 2초 제한 서버에서 시간 초과 폴드 확인 |
| 실제 인원 제한 | 7번째 참가 거절, 좌석 해제 후 새 참가 확인 |
| Swing 테이블 렌더링 | 실제 TablePanel을 headless 이미지로 렌더링해 배치 확인 |

검증 한계: Windows에서 배치 파일을 실행하거나 Eclipse 가져오기와 GUI 버튼을 직접 클릭하는 테스트는 이 환경에서 수행하지 않았습니다. 테스트 환경에 한글 폰트가 없어 headless 이미지의 한글 글리프는 확인하지 못했습니다. Windows의 한글 시스템 폰트가 있는 데스크톱 환경에서 최종 GUI 확인이 필요합니다. 네트워크 테스트의 클라이언트는 Python 소켓 테스트 클라이언트이며 Swing 앱 자체를 자동 조작한 테스트는 아닙니다.

반복 실행 방법은 README의 ‘수정 후 빌드와 테스트’를 참고하세요. `tests/network_test.py`는 테스트 서버를 임시 로컬 포트에 띄웠다가 종료합니다.
